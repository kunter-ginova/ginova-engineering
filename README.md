# GiNOVA Engineering

Static source for https://engineering.ginova.net/. Publish the repository root through GitHub Pages after custom-domain and DNS approval. No installation or build is needed.

The website content, translations, assets, media and controls match the accepted production source. Original media remain alongside current derivatives. Enquiries open email drafts locally; there is no checkout, SaaS backend or server-side form storage.

Keep CNAME set to engineering.ginova.net. The default GitHub project subpath is not a substitute for the custom domain: assets use domain-root paths.
